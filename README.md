# DataProof AI: Proof-Carrying Data Analyst

HNX26PSI08 · Agentic GenAI · Data Analytics · Code Generation · Verification

DataProof AI answers questions about messy, multi-table business data. Every number comes with re-runnable pandas code, and the answer is checked by a second, independent method. If the data can't support an answer, the agent says "Cannot determine" and explains why instead of guessing.

## How it works

1. The user asks a question (chip, text box, or uploaded CSV).
2. A deterministic pre-check looks for unanswerable or ambiguous questions (missing column, unknown entity, ambiguous date or currency).
3. The LLM writes pandas proof code. The code is executed in a separate process with a timeout.
4. The code is run again fresh, and the answer is recomputed by an independent method.
5. The result gets one verdict:
   - VERIFIED: both methods agree
   - AMBIGUOUS: the question has more than one valid reading
   - CANNOT DETERMINE: the data cannot answer it
   - NOT VERIFIED: the methods disagree
6. The user can download the proof script and re-run it to get the same number.

## Messy-data traps handled

| Trap | How the agent handles it |
|---|---|
| Unit mismatch ($ / ₹ / €) | Converts using a stated rate and shows the assumption |
| Ambiguous dates (e.g. 03/04/2026) | Flags the ambiguity and states the interpretation used |
| Duplicate rows | Detects and removes them, and reports how many |
| Tables that contradict each other | Reports which records disagree and which source was trusted |
| Missing data | Reports excluded rows instead of silently dropping them |
| Unanswerable questions (e.g. profit with no cost column) | Refuses with a reason |
| Trick questions (nonexistent customer, impossible date) | Refuses with a reason |

## Setup and run

Requirements: Python 3.10 or newer.

```bash
git clone <YOUR-REPOSITORY-LINK>
cd DataProofAI
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Set the API key (optional; without it the app runs in mock mode):

```bash
# Windows PowerShell
$env:GEMINI_API_KEY="your-key"
# Mac/Linux
export GEMINI_API_KEY="your-key"
```

Run the app:

```bash
streamlit run app.py
```

Run the test suite:

```bash
python evaluate.py
```

Regenerate the sample data and answer key:

```bash
python gen_data.py
```

Re-run any downloaded proof script:

```bash
python proof_<question>.py
```

## Limitations

- The code sandbox uses a separate process and a timeout, but it does not fully block file or network access. Do not run it on untrusted input.
- Uploaded CSVs work best when they have columns similar to the sample data, and unusual schemas may produce "Cannot determine".
- Exchange rates are fixed assumptions, not live rates.
- The LLM can still misread an unusual question. The verification step reduces this risk but does not remove it.
- Only a small test set has been run, so scores on other questions may differ.
